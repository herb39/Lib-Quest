# 📚 Lib Quest

**도서관이 퀘스트가 되는 순간.**

Lib Quest는 실제 도서관 장서를 탐험 콘텐츠로 바꾸는 모바일 웹 서비스입니다. 이용자는 미션을 따라 실제 서가를 이동하고, 책의 ISBN을 인증해 숨겨진 책을 발견합니다. 검색으로 추천받는 대신 직접 책장을 걸어, 평소라면 지나쳤을 책을 만나도록 설계했습니다.

**[🌐 서비스 체험하기 →](https://quest.lib.lc)**
**[🛠 운영자 콘솔 →](https://quest.lib.lc/admin/review)** *(`DEMO ADMIN` — 로그인 없는 공모전 데모 환경입니다)*

---

## 왜 Lib Quest인가요?

도서관에는 훨씬 많은 책이 있지만, 이용자는 인기 도서·신착 도서·이미 알고 있는 책 위주로만 접근하기 쉽습니다.

검색·추천 서비스가 **무엇을 읽을지 알려주는 것**이라면, Lib Quest는 **직접 서가를 걷고 책을 발견하게 만드는 것**에 초점을 둡니다.

## 책장을 걷고, 책을 발견합니다

```
Quest 선택 → Mission 확인 → 실제 서가 이동 → ISBN 인증 → 책 발견 → 책 살펴보기 → 읽어보고 싶어요 → 오늘의 한 권
```

- 실제 서가로 이동해 숨겨진 책을 찾고 ISBN을 인증하면, 그 책이 실제 표지를 가진 3D 오브젝트로 눈앞에 나타납니다.
- 정답 판정은 항상 서버가 실제 도서 데이터와 비교해서 내립니다 — AI가 임의로 판단하지 않습니다.
- 발견한 책은 소개와 "끌리는 이유"를 살펴보고, 마음에 들면 `읽어보고 싶어요`로 담아둡니다.
- Quest를 마치면 그날 만난 책들 중 오늘 읽을 한 권을 직접 고르고 탐험 결과를 확인합니다.

카메라 스캔이 어려운 환경이어도 ISBN 직접 입력만으로 끝까지 진행할 수 있습니다.

## 무엇이 다른가요?

**실제 장서가 게임 콘텐츠가 됩니다.** 가상의 책이나 임의 추천이 아니라, 도서관 정보나루의 실제 장서 데이터로 Quest를 구성했습니다.

**화면 안에서 끝나지 않습니다.** Mission이 이용자를 실제 서가로 이동시키고, ISBN 인증으로 실제 발견을 확인합니다.

**발견 이후까지 이어집니다.** 책을 발견한 순간의 기쁨에서 그치지 않고, `읽어보고 싶어요`와 `오늘의 한 권`으로 독서 관심까지 이어갑니다.

**운영자가 콘텐츠를 관리합니다.** 사서·운영자는 후보 도서를 확인하고, Mission 문구와 책 소개를 직접 수정·검수·공개할 수 있습니다.

## 지금 실제로 구현되어 있습니다

- 대전 지역 4개 도서관, 실제 큐레이션 장서 144권
- Quest 12개 · Step 36개 · 후보 도서 144건
- ISBN 카메라 바코드 스캔 및 직접 입력 인증
- 발견 순간을 위한 3D Book Discovery
- 발견 도감 · XP · 탐험 칭호(모두 브라우저에 저장되는 개인 기록이며 로그인은 없습니다)
- 읽어보고 싶어요, 오늘의 한 권 선택과 탐험 결과 화면
- 운영자 콘솔에서 Mission·책 소개 콘텐츠 작성·검수·공개, 데모 콘텐츠 초기화

## 대표 탐험

**대전 원신흥도서관**의 `익숙한 문학, 낯선 이야기`를 대표 시연 경로로 준비했습니다.

```
원신흥도서관 선택 → Quest 선택 → Mission 확인 → 서가 이동 → ISBN 인증 → 발견 → 오늘의 한 권
```

실제 정답 ISBN과 상세 진행 경로는 **[시연 가이드](docs/DEMO_GUIDE.md)**에 정리되어 있습니다.

현재 대전 지역 4개 도서관(원신흥·갈마·가수원·노은)의 실제 장서를 적용하고 있으며, 도서관마다 같은 콘셉트의 퀘스트를 각자의 실제 소장 도서로 별도 구성해 두었습니다.

## 도서관 데이터는 이렇게 활용합니다

```
도서관 정보나루 실제 장서 → Quest 후보 구성 → 운영 콘텐츠 작성·검수 → 이용자의 실제 서가 탐험 → ISBN 인증 → 책 발견
```

- 도서관별 실제 장서(ISBN·분류·청구기호·서가 위치)를 그대로 Quest 구성에 활용합니다.
- 후보 도서와 콘텐츠는 운영자 검수를 거쳐야 이용자에게 공개됩니다.
- 실시간 대출 가능 여부를 제공하는 서비스는 아닙니다 — 사전에 검증해 저장해 둔 등록 정보만 사용합니다.

자세한 수집 기간·건수는 **[데이터 출처 화면](https://quest.lib.lc/data-source)**에서 확인할 수 있습니다.

## 도서관은 어떻게 운영하나요?

```
실제 장서 → 후보 구성 → Mission/책 소개 작성 → 운영자 검수 → 공개 → 이용자 탐험
```

운영자 콘솔(`/admin/review`)에서 Mission 문구와 책 소개(hook·teaser·질문)를 수정하고, 검수 상태와 공개 여부를 관리하며, 발표 전 데모 콘텐츠를 초기 상태로 되돌릴 수 있습니다. 사용법은 **[운영자 가이드](docs/OPERATOR_GUIDE.md)**를 참고하세요.
