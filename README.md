# Lib Quest

도서관의 실제 서가를 탐색하며 예상하지 못한 책을 발견하는 참여형 모바일 웹 콘텐츠.

공식 서비스: **https://quest.lib.lc**

대표 시연 도서관: **대전 원신흥도서관**

현재 대전 지역 4개 도서관의 실제 장서 데이터를 적용했다: 대전 원신흥도서관(대표 시연) · 대전 갈마도서관 · 대전 가수원도서관 · 대전 노은도서관.

## 체험하기

- [서비스 체험](https://quest.lib.lc) — 퀘스트를 직접 진행해본다
- [운영자 검수](https://quest.lib.lc/admin/review) — 실제 후보 도서와 서가 정보를 확인한다
- [데이터 출처](https://quest.lib.lc/data-source) — 어떤 데이터를 어떻게 수집했는지 확인한다

## Lib Quest란?

- 단순히 책을 추천해주는 서비스가 아니다.
- 실제 서가를 걸어 다니며 책을 찾는 경험을 퀘스트로 만들었다.
- 책을 고르는 건 서비스가 아니라 이용자 자신이다.
- 찾은 책의 ISBN을 인증해야 다음 단계가 열린다.
- 정답 판정은 항상 서버가 실제 도서 데이터(ISBN)와 비교해서 내리며, AI가 임의로 판단하지 않는다.
- 서가에 이미 있는 책을 새롭게 발견하도록 유도하는 것이 목적이다.
- 한 퀘스트 안에서 서로 다른 분야의 서가를 옮겨 다니는 경험을 제공한다.

## 대상별 안내

### 일반 사용자 — 도서관에서 퀘스트를 수행하는 이용자

1. `https://quest.lib.lc` 접속
2. 이용할 도서관 선택 (4곳 중 하나)
3. 퀘스트 선택
4. 미션(찾아야 할 책의 힌트) 확인
5. 안내된 자료실·서가로 이동해 책 찾기
6. 책 뒷면의 ISBN 바코드를 카메라로 스캔
7. 스캔이 어려우면 ISBN을 직접 입력
8. 해당 단계의 후보 도서와 일치하면 다음 단계로 진행
9. 3단계까지 반복
10. 발견한 책 목록과 함께 완료 결과 카드 확인

카메라 권한을 허용하지 않거나 카메라를 사용할 수 없는 환경이어도, ISBN 직접 입력만으로 퀘스트를 끝까지 진행할 수 있다.

**현재 이용 가능한 퀘스트** (도서관마다 동일한 콘셉트를 실제 소장 도서로 별도 구성):

- **익숙한 문학, 낯선 이야기** — 문학 서가에서 한국·일본·영미 소설을 한 권씩 만난다.
- **서로 다른 서가로 떠나는 지식 여행** — 사회과학, 자연과학, 예술 서가를 차례로 옮겨 다니며 전혀 다른 세 권을 찾는다.
- **짧은 시간, 세 권의 발견** — 철학, 역사, 실용과학 서가를 빠르게 오가며 짧은 시간 안에 세 권을 발견한다.

### 운영자 — 사서 등 도서/퀘스트 후보를 검수하는 사람

퀘스트 후보 도서와 실제 서가 정보를 검수하는 방법은 **[운영자 가이드](docs/OPERATOR_GUIDE.md)** 참고.

### 개발자 / 시스템 관리자 — 코드/DB/인프라를 유지보수하는 사람

프로젝트 구조, API, DB, Data4Library 수집, Prisma, Neon, Vercel, 환경변수, 배포 절차는 **[개발 문서](docs/DEVELOPMENT.md)** 참고.

### 심사자 / 발표자 — 공모전 데모를 검토 또는 시연하는 사람

실제 도서관에 방문하지 않고 ISBN 직접 입력으로 전체 흐름을 확인할 수 있는 시연 가이드는 **[시연 가이드](docs/DEMO_GUIDE.md)** 참고.

## 데이터 출처

활용 데이터: 도서관 정보나루(Data4Library), 활용 도서관: 대전 원신흥도서관(libCode `130026`, 대표 시연) · 갈마도서관 · 가수원도서관 · 노은도서관, 활용 필드: ISBN·제목·저자·KDC 분류·청구기호·자료실/서가 위치.

서비스 이용 중에는 Data4Library를 실시간으로 호출하지 않고, 사전에 검증해 Neon DB에 저장해 둔 데이터만 사용한다. 이 데이터는 도서관에 실제로 등록되어 있다는 뜻이며, 지금 이 순간의 대출 가능 여부를 의미하지는 않는다.

자세한 수집 기간·건수·필드는 [데이터 출처 화면](https://quest.lib.lc/data-source)에서 실시간으로 확인할 수 있다.
