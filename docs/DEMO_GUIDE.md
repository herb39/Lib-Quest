# Lib Quest 시연 가이드

**대상: 심사자 / 발표자**

실제 대전 원신흥도서관에 방문하지 않고도, ISBN 직접 입력만으로 서비스 전체 흐름을 확인할 수 있는 시연 시나리오다.

서비스는 현재 대전 지역 도서관 4곳(원신흥·갈마·가수원·노은)을 지원하지만, 이 가이드는 발표 대표 시연 도서관인 **원신흥도서관** 기준으로만 작성한다. 다른 도서관도 동일한 구조(퀘스트 3개 × 3단계 × 후보 4권)로 동작하며, 필요하면 `/admin/review`에서 원하는 도서관을 선택해 같은 방식으로 실제 candidate ISBN을 확인할 수 있다.

아래 ISBN·책 제목·청구기호·서가 위치는 모두 `data/libraries/130026/quest-curation.json` + `data/libraries/130026/collected-books.json`에 실제로 들어있는 값이며, 2026-08-19에 production DB(Neon)에서 verify API로 직접 재현·검증했다 (Part 18 참고). 임의로 만든 값은 없다. 발견 성공 시 함께 보여주는 teaser/hook/question은 `data/libraries/130026/book-editorial.json`, Step 진입 시 보여주는 미션 제목/서사는 `data/libraries/130026/quest-missions.json`에 저장된 Lib Quest 자체 편집 콘텐츠다(실제 제목·부제·저자·KDC 분류에 근거해 작성, 실시간 AI 생성 아님 — [SERVICE_DESIGN.md](SERVICE_DESIGN.md) 참고). 청구기호는 후보마다 달라 정답을 특정할 수 있으므로 화면에는 발견 **성공 후에만** 표시된다 — 아래 표의 청구기호는 시연자가 참고할 실제 값일 뿐, 인증 전 화면에 나타나는 정보가 아니다.

접속: **https://quest.lib.lc**

퀘스트 ID(URL의 `/quests/xxxx` 부분)는 DB를 다시 시드하면 바뀔 수 있으므로, 아래 시나리오는 항상 퀘스트 **제목**으로 선택하는 방식으로 안내한다.

## 테스트 상태 초기화

리허설이나 새 기기(특히 iPhone Safari, 네이버 앱 내부 브라우저처럼 개발자도구 접근이 어려운 환경)에서 완전히 새 사용자 상태로 다시 시작하고 싶을 때 사용한다.

1. 아무 화면에서나 Header 우측의 `↻ 처음부터` 클릭 (단, `/admin/review`에는 이 버튼이 없다 — 운영자 화면은 사용자 진행 상태와 무관하므로)
2. "탐험을 처음부터 시작할까요?" 확인 대화상자에서 `처음부터 시작` 클릭
3. 자동으로 홈(`/`)으로 이동
4. 발견한 책 수/XP/칭호가 초기 상태("아직 발견한 책이 없어요")로, 모든 도서관 카드가 `0 / 36 발견`으로, 이전에 진행하던 Quest가 있었다면 다시 "오늘의 탐험" 소개 화면부터 시작하는지 확인

이 초기화는 발견 도감·관심 표시·오늘의 한 권 선택·진행 중이던 모든 Quest 기록을 한 번에 지운다. 브라우저의 다른 사이트 데이터에는 영향을 주지 않는다.

## 시나리오 A. 퀘스트 정상 완주

사용 퀘스트: **익숙한 문학, 낯선 이야기** (3단계, 종합자료실 문학 서가 → 한국·일본·영미 소설)

> **발표 팁**: 6번의 Discovery 화면(큰 책이 나타나는 순간)이 이번 데모에서 가장 중요한 장면이다. `책 살펴보기`를 서둘러 누르지 말고 2~3초 정도 화면을 유지해 심사위원이 실제 표지가 공개되는 순간을 볼 수 있게 한다.

0. (리허설 시) 위 "테스트 상태 초기화" 절차로 완전히 새 사용자 상태에서 시작
1. `https://quest.lib.lc` 접속
2. "대전 원신흥도서관" 카드("대표 시연" 배지)의 `퀘스트 보기` 클릭
3. **익숙한 문학, 낯선 이야기** 선택 → "오늘의 탐험" 소개 화면에서 `탐험 시작하기` 클릭
4. 1단계 확인 — 발견 슬롯 3개(전부 `?`), `MISSION 1 / 3` · 미션 제목("첫 번째 흔적") · 짧은 탐험 서사, "이번 미션"(실제 행동 지시), "탐험 단서"(📍 종합자료실 · 📚 문학 > 한국문학 > 소설 · 🔎 발견 후보 4권 — 정확한 청구기호는 아직 안 보임), 두께가 있는 큰 3D 책 오브젝트(hidden 상태, `?` / 숨겨진 책) 확인
5. "ISBN-13" 입력창에 아래 값을 직접 입력하고 `책 발견하기` 클릭

   | 항목 | 값 |
   | --- | --- |
   | Step | 1단계 · 우리말로 쓰인 새 이야기 |
   | 입력 ISBN | `9791141617226` |
   | 실제 책 제목 | 시간의 감촉 :은희경 장편소설 |
   | 저자 | 은희경 |
   | 청구기호 | 은942ㅅ |
   | 서가 위치 | 종합자료실 |

6. **Discovery 화면 확인(가장 중요한 순간)** — Mission 화면이 사라지고, "새로운 책 발견" 레이블과 함께 화면 대부분을 차지하는 매우 큰 3D 책이 나타나는지, 표지가 실제로 공개되고 책등/페이지 두께가 보이는지 확인. 이 화면에는 제목(`시간의 감촉 :은희경 장편소설`)/저자(은희경)/`+10 XP`만 있고, hook/teaser/question 같은 텍스트 정보는 **아직 없어야** 한다(발표자는 이 화면에서 잠깐 멈춰 책 자체를 보여준다)
6-1. `책 살펴보기` 버튼 클릭 → Book Info 화면으로 전환 — 작아진 책 표지 옆에 제목/저자, 그 아래 "이 책이 끌리는 이유"(hook)가 먼저 보이는지, `♡ 읽어보고 싶어요` 버튼이 있는지 확인. 버튼을 눌러 `♥ 읽어보고 싶은 책에 담았어요`로 바뀌는지 확인(이 책만 관심 표시). `책 더 알아보기`를 펼치면 "이런 책이에요"(teaser)/"책을 펼치기 전에"(question)가 나오는지 확인
7. `다음 탐사지역 열기` 버튼 클릭 → 2단계로 이동, 발견 슬롯 1번이 표지로 채워져 있는지 확인 후 아래 ISBN 입력

   | 항목 | 값 |
   | --- | --- |
   | Step | 2단계 · 바다 건너 온 이야기 |
   | 입력 ISBN | `9791192738819` |
   | 실제 책 제목 | 죽음의 인연 :붉은 박물관 |
   | 저자 | 오야마 세이이치로 |
   | 청구기호 | 오615ㅂ |
   | 서가 위치 | 종합자료실 |

8. Discovery 화면(+10 XP) 확인 → `책 살펴보기` → Book Info 화면에서 hook 확인 → `다음 탐사지역 열기` 클릭 → 3단계로 이동
9. 3단계에서 아래 ISBN 입력

   | 항목 | 값 |
   | --- | --- |
   | Step | 3단계 · 지구 반대편 이야기 |
   | 입력 ISBN | `9791170403937` |
   | 실제 책 제목 | 마고가 돈 문제에 대처하는 법 :루피 소프 장편소설 |
   | 저자 | 소프, 루피 |
   | 청구기호 | 소419ㅁ |
   | 서가 위치 | 종합자료실 |

10. Discovery 화면(+10 XP) → `책 살펴보기` → Book Info 화면에서는 `다음 탐사지역 열기` 대신 `결과 카드 보기` 버튼이 표시된다. 클릭
11. **"오늘 만난 세 권" 선택 화면 확인** — 발견한 3권이 카드로 나열되고 "이 중 한 권을 골라볼까요?" 안내가 보이는지 확인. 아무 카드(예: `죽음의 인연`)를 탭
12. **"오늘의 선택" 화면 확인** — 선택한 책의 표지·제목·hook이 크게 표시되고 "이제 책을 펼쳐볼까요?" 문구가 보이는지 확인 (여기서 "대출하기"처럼 실제 대출을 의미하는 문구가 없는지도 함께 확인)
13. 그 아래로 이어지는 결과 카드에서 위 3권이 표지와 함께 순서대로, 탐험 흐름(1단계→2단계→3단계 제목)과 함께 표시되는지 확인
14. 페이지를 새로고침해 "오늘의 선택"이 그대로 유지되는지(선택 화면이 다시 뜨지 않는지) 확인
15. Header 좌측 `📚 Lib Quest` 로고 클릭 → 홈에서 "나의 탐험"에 칭호(예: `첫 방문자`), `⭐ 30 XP`, `📚 발견한 책 3권`이 표시되는지, 원신흥 카드에 `3 / 36 발견` 진행도가 표시되는지 확인
16. "나의 탐험"의 `발견 도감 보기` 클릭 → `/discoveries` 진입 → 방금 발견한 책 3권이 표지와 함께 나열되고, `♥ 읽어보고 싶어요 1권` 필터가 앞서 담은 책과 일치하는지, 도서관별 진행도에 "대전 원신흥도서관 3/36"이 표시되는지 확인

## 시나리오 B. 잘못된 ISBN 검증

목적: "ISBN 문자열이 존재하기만 하면 통과하는 것이 아니라, **현재 단계의 후보 도서 DB와 서버가 직접 비교해서** 판정한다"는 것을 보여준다.

1. 시나리오 A와 동일하게 **익숙한 문학, 낯선 이야기**의 1단계까지 진입 (또는 새로고침 후 1단계부터)
2. 1단계 입력창에, **실제로 존재하지만 2단계 후보인** ISBN을 입력

   | 항목 | 값 |
   | --- | --- |
   | 입력 위치 | 1단계 · 우리말로 쓰인 새 이야기 |
   | 입력 ISBN | `9791192738819` (2단계 "죽음의 인연" 후보 ISBN — 실제 존재하는 도서 데이터) |

3. `책 발견하기` 클릭
4. 기대 결과: **실패** — "이 단계의 후보 도서가 아니에요. 다시 확인해주세요." + "다른 책을 찾아볼까요?" 메시지가 부드러운 카드로 표시되고, 단계가 넘어가지 않음 (Mission 화면 그대로 유지되며 Discovery 화면으로 전환되지 않음)

이 케이스는 2026-08-19에 production verify API(`/api/quests/.../steps/.../verify`)로 직접 호출해 `{"success": false, "message": "이 단계의 후보 도서가 아니에요. 다시 확인해주세요."}` 응답을 확인했다 (실존하지 않는 ISBN이 아니라, **실존하지만 다른 단계의 정답**이라는 점이 핵심).

## 시나리오 C. 운영자 검수 → 사용자 검증 연결

목적: "운영자가 검수한 실제 후보 데이터 → 이용자의 ISBN 검증"이 실제로 이어진다는 것을 보여준다.

1. 메인 화면(`/`)에서 `운영자 검수` 클릭
2. `/admin/review` 진입 (기본으로 "대전 원신흥도서관" 탭이 선택되어 있음). 상단에 `Data4Library 후보 → 콘텐츠 작성 → 운영자 검수 → 이용자 공개` workflow 표시 확인
3. **익숙한 문학, 낯선 이야기** 섹션에서 1단계 후보 도서 4권 확인 (제목/저자/ISBN/KDC/청구기호/서가위치/출처)
3-1. "시간의 감촉" 행의 `콘텐츠 보기`를 펼쳐 `검수된 콘텐츠` 배지와 함께 한 줄 훅/teaser/읽기 전 질문이 보이는지 확인
4. 아무 후보(예: "시간의 감촉") 행의 ISBN 옆 `복사` 버튼 클릭 → "ISBN을 복사했습니다." 표시 확인
5. Header 좌측 `📚 Lib Quest` 로고 클릭 → 홈 → "대전 원신흥도서관" 카드의 `퀘스트 보기` → **익숙한 문학, 낯선 이야기** 진입(이미 시작한 퀘스트라 소개 화면 없이 바로 이어짐)
6. 1단계 ISBN 입력창에 붙여넣기
7. `책 발견하기` 클릭 → Discovery 화면에서 큰 3D 책과 함께 성공 확인

## 시나리오 D. 데이터 출처 확인

1. 메인 화면(`/`)에서 `데이터 출처` 클릭
2. `/data-source` 진입
3. 활용 데이터가 "도서관 정보나루(Data4Library) itemSrch"로 표시되는지 확인
4. "활용 도서관: 4곳" 요약과 함께 4개 도서관이 모두 나열되는지 확인
5. "대전 원신흥도서관 (libCode 130026)" 항목에서 수집 기간(2026-06-01~2026-08-19), 원본 조회 300건, 큐레이션 도서 36권이 표시되는지 확인
6. 하단 안내에서 "실시간으로 Data4Library를 호출하지 않는다", "등록일 기준이며 실시간 대출 가능 여부가 아니다"라는 설명 확인

## 참고: 카메라 스캔 없이 진행하는 이유

발표 환경에서 실제 도서 실물이 없으므로 카메라 바코드 스캔 대신 위 ISBN을 직접 입력해 시연한다. 카메라 스캔 기능 자체는 별도로 동작하며(`@zxing/browser` 기반, `docs/DEVELOPMENT.md` 참고), 이 문서의 목적은 실물 없이도 서버 판정·퀘스트 진행·완료 카드까지 전체 흐름을 보여주는 것이다.
