# Lib Quest 운영자 가이드

**대상: 사서 / 콘텐츠 운영자** (개발자용 문서가 아니다. 코드/서버 관련 내용은 [DEVELOPMENT.md](DEVELOPMENT.md) 참고)

## 왜 이 화면을 보는가

Lib Quest는 실제 장서 데이터를 사람이 검수한 뒤에만 이용자에게 공개하는 구조다.

```
Data4Library 후보 → 콘텐츠 작성 → 운영자 검수 → 이용자 공개
```

- **데이터가 결정하는 것**: 어떤 책이 실제로 서가에 있는지, ISBN·청구기호·서가 위치가 무엇인지 — Data4Library `itemSrch` 원본 그대로.
- **사람이 결정하는 것**: 그 후보들이 Quest 후보로 적절한지, teaser/hook/question 문구가 그 책에 실제로 맞는 내용인지, 이용자에게 공개해도 되는지.

운영자는 다음을 확인하는 역할을 한다.

- Quest(퀘스트) 구성 확인
- Step(단계) 확인
- 각 단계의 후보 도서 확인
- ISBN 확인
- KDC(분류) 확인
- 청구기호 확인
- 서가/자료실 위치 확인
- **이용자에게 보여줄 콘텐츠(teaser/hook/question) 확인**
- 데이터 출처 확인

## 검수 화면 접속

**https://quest.lib.lc/admin/review**

메인 화면(`https://quest.lib.lc`)의 `운영자 검수` 버튼으로도 들어갈 수 있다.

로그인이나 별도 권한이 필요하지 않다 (읽기 전용 화면).

## 화면 구성

`/admin/review`는 PC(데스크톱)에서 보기 편하도록 구성되어 있다.

1. **도서관 탭** — 상단에 서비스가 지원하는 도서관(현재 4곳)이 탭으로 나열된다. 탭을 클릭하면 `/admin/review?library=libCode`로 이동해 해당 도서관 데이터만 보여준다. 기본으로는 대표 시연 도서관(원신흥도서관)이 선택되어 있다.
2. **선택한 도서관 정보** — 도서관명, libCode, 요약 카드(퀘스트 수 / 단계 수 / 후보 도서 수 / 실제 활용 도서 수)
3. **퀘스트별 검수 영역** — 퀘스트 제목, 테마, 난이도, 게시 상태(게시됨/미게시)가 위에 표시되고, 그 아래 단계별로 후보 도서 표가 이어진다.
4. **단계별 후보 도서 표** — 한 단계에 보통 4권의 후보 도서가 있으며, 그중 하나가 "대표" 표시가 붙은 기본 후보다. (다른 후보로도 정답 처리되며, 대표는 화면에 기본으로 보여주는 후보일 뿐이다.)

같은 퀘스트 이름(예: "익숙한 문학, 낯선 이야기")이 여러 도서관에 반복해서 나타날 수 있다 — 도서관마다 그 도서관의 실제 소장 도서로 별도 구성된 동명의 퀘스트이며, 후보 도서는 서로 다르다.

## 후보 도서 검수

표의 각 열은 다음을 의미한다.

| 열 | 확인할 내용 |
| --- | --- |
| 대표 | 화면에 기본으로 노출되는 후보인지 여부 (다른 후보도 정답으로 인정됨) |
| 제목 | 실제 도서명 |
| 저자 | 실제 저자명 |
| ISBN | 13자리 ISBN. 이용자가 서가에서 이 번호로 책을 확인한다 |
| KDC | 한국십진분류 번호 |
| 분류명 | KDC 번호가 의미하는 분류(예: 문학 > 한국문학 > 소설) |
| 청구기호 | 서가에서 책을 찾을 때 보는 표기 |
| 자료실/서가 | 책이 있는 자료실 이름 (예: 종합자료실) |
| 데이터 출처 | 이 정보가 어디서 왔는지 (현재는 모두 도서관 정보나루 `itemSrch` 수집 결과) |

이 정보가 실제 서가 상황과 다르면(책이 다른 곳으로 옮겨졌거나 폐기된 경우 등) 개발팀에 알려 해당 도서관의 큐레이션 데이터(`data/libraries/<libCode>/quest-curation.json`)를 다시 검토해야 한다. **이 화면 자체에서 직접 수정하는 기능은 없다** (아래 "현재 MVP 제약" 참고).

## 이용자 노출 콘텐츠 검수

각 후보 도서 행 아래 `콘텐츠 보기`를 펼치면 이용자가 책을 발견했을 때 보게 될 문구를 확인할 수 있다.

| 항목 | 의미 |
| --- | --- |
| 한 줄 훅(hook) | "이 책이 끌리는 이유" — 발견 직후 가장 먼저 보여주는, 읽고 싶게 만드는 한 줄 |
| teaser | "이런 책이에요" — 2~3줄 이내의 짧은 소개 |
| 읽기 전 질문(question) | "책을 펼치기 전에" — 내용에 관심을 갖게 하는 질문 |

배지가 `검수된 콘텐츠`면 세 문구가 모두 작성되어 이용자 화면에 노출된다는 뜻이고, `콘텐츠 없음`이면 아직 작성되지 않아 이용자 화면에는 표지·제목·저자·XP까지만 보이고 콘텐츠 영역 자체가 나타나지 않는다는 뜻이다(실제로 없는 문구를 빈 칸으로 어색하게 보여주지 않는다).

**이 화면에서 콘텐츠를 직접 수정하거나 저장할 수는 없다.** 문구가 실제 책 내용과 맞지 않거나 부적절하면 개발팀에 알려 `data/libraries/<libCode>/book-editorial.json`을 수정해야 한다. 운영자가 화면에서 직접 편집하는 기능은 인증/권한 체계가 필요해 아직 만들지 않았다 — [SERVICE_DESIGN.md](SERVICE_DESIGN.md)의 roadmap 참고.

현재 teaser/hook/question은 **대전 원신흥도서관 36권 전체**에 작성되어 있다. 다른 3개 도서관(갈마·가수원·노은)은 아직 작성되지 않아 `콘텐츠 없음`으로 표시된다 — 이는 오류가 아니라 근거 없는 문구를 억지로 채우지 않기 위한 의도된 상태다.

### 향후 검수 대상 (아직 이 화면에 없음)

Step 진입 시 사용자가 보는 미션 제목/짧은 서사(Mission Narrative, `missionTitle`/`missionNarrative`)도 teaser/hook/question과 마찬가지로 사람이 작성·검수해야 하는 콘텐츠다. 현재 대전 원신흥도서관의 3개 Quest × 3 Step(9개) 전체가 `data/libraries/130026/quest-missions.json`에 작성되어 있지만, **이 화면(`/admin/review`)에서는 아직 확인할 수 없다** — teaser/hook/question처럼 화면에 노출하는 기능은 향후 계획일 뿐 지금 동작하는 기능이 아니다.

## ISBN 복사

발표·데모 환경에서는 실제 도서관에 가지 않고도 후보 도서의 ISBN을 그대로 복사해 사용자 화면의 "ISBN 직접 입력"에 붙여넣어 테스트할 수 있다.

1. `/admin/review`에서 확인하고 싶은 후보 도서의 ISBN 옆 `복사` 버튼 클릭
2. "ISBN을 복사했습니다." 문구가 잠깐 표시되면 클립보드에 복사된 것
3. 사용자 퀘스트 화면(`/quests/...`)의 ISBN 입력창에 붙여넣고 확인

이 기능은 `/admin/review` 안에서만 제공되며, 일반 사용자 화면에는 후보 ISBN이 미리 노출되지 않는다.

## 데이터 출처

**https://quest.lib.lc/data-source**

어떤 API로, 언제, 몇 건을 수집했는지는 이 화면에서 확인한다. 자세한 내용은 이 화면 자체의 설명을 참고한다.

## 현재 MVP 제약

- **읽기 전용 검수만 가능하다.** `/admin/review`에서 도서·퀘스트 정보를 직접 추가/수정/삭제할 수 없다.
- **로그인/권한 시스템이 없다.** URL을 아는 사람은 누구나 볼 수 있는 화면이다.
- **실시간 대출 가능 여부를 보여주지 않는다.** 표시되는 정보는 특정 시점에 수집된 등록 정보이며, 지금 이 순간 대출 가능한지와는 무관하다.
- **대전 지역 도서관 4곳(원신흥·갈마·가수원·노은)만 지원한다.** 그 외 도서관 데이터는 없다. 대표 시연 도서관은 여전히 원신흥도서관이다.
- **발표용 MVP다.** 통계, 자동 큐레이션, 도서관 자동 추가 같은 기능은 아직 없으며, 향후 계획일 뿐 지금 동작하는 기능이 아니다.
- **콘텐츠(teaser/hook/question) 편집·검수 상태 저장 기능이 없다.** 정적 저장소 값을 읽기 전용으로 보여줄 뿐이다. 향후 편집 기능은 운영자 인증이 먼저 갖춰진 뒤 진행할 계획이다.
